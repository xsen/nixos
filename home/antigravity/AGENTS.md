# Глобальные правила Antigravity

- **Язык общения:** Всегда отвечай пользователю на русском языке.
- **Язык разработки:** Код, технические комментарии, логи, системные сообщения и коммиты пиши строго на английском. **Исключение:** UI и файлы локализации (i18n, json) пиши на языке целевой аудитории проекта (по умолчанию русский).

## Браузерная автоматизация и MCP
- **Приоритет:** Для веб-автоматизации и отладки по умолчанию используй **Chrome DevTools** (`chrome-devtools-mcp`). Playwright — только по прямому запросу.
- **Окружение (NixOS):** Браузер запускается автоматически через обертку `launch-chrome-mcp.sh` на порту 9222.
- **Режимы запуска:** Учитывай переменные `AGY_CHROME_HEADLESS=false` (headed-режим с окном) и `AGY_CHROME_ISOLATED=false` (постоянный профиль `~/.config/chrome-mcp-profile`). При необходимости специфического режима запусти Chrome в фоне на порту 9222 перед вызовом MCP.
- **Параметры MCP:** Для `chrome-devtools` включен `--no-page-id-routing` (передавать `pageId` в `navigate_page`, `take_screenshot` и др. не требуется; они по умолчанию работают с активной вкладкой).

## Качество и Workflow
- **Коммиты:** Никогда не делай коммиты (`git commit`) самостоятельно без явной просьбы пользователя.
- **Паттерн "Plan-First":** Для задач, затрагивающих >2 файлов или сложную архитектуру, сначала представь краткий план и жди подтверждения пользователя («ОК», «делай»). При критических ошибках сборки/тестов остановись и перепланируй. Лимит автоисправлений одной ошибки — 2 попытки.
- **Code Review Workflow:** Для нетривиальных изменений перед сдачей задачи запусти навык [code-review](file:///home/evgeny/.gemini/config/skills/code-review/SKILL.md). Исключения: тривиальные правки (<10 строк в 1 файле) или явная просьба пользователя пропустить ревью.
